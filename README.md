# 💳 Simple ATM System in Java

## 🚀 Project Overview

This is a basic ATM simulation program written in Java. It allows users to authenticate using a User ID and PIN, then perform common banking operations such as viewing transaction history, withdrawing money, depositing funds, and (planned) transferring funds.

The program models users, transactions, and ATM operations using classes and demonstrates core object-oriented programming principles.

---

## ✨ Features

- 🔐 **User Authentication:** Users log in with a User ID and PIN.
- 📜 **Transaction History:** View a history of deposits and withdrawals.
- 💸 **Withdrawals:** Withdraw money from the account (if sufficient balance exists).
- 💰 **Deposits:** Deposit money into the account.
- 🔄 **Transfer:** Placeholder for future implementation of transferring funds between users.
- 🖥️ **Simple CLI Interface:** Interact with the system via the command line.
